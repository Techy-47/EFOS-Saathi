# EFOS Saathi — AI Career Guidance Chatbot

**EFOS Saathi** is an AI-powered multilingual career guidance chatbot and voice assistant built for EFOS.in. It is designed to help rural and semi-urban students get personalized career guidance, skill roadmaps, scholarship direction, job/internship guidance, parent-friendly explanations, and EFOS counselor support.

This project was developed as a hackathon prototype with a clean EFOS-inspired UI, Gemini AI integration, voice input, manual voice reply, lead capture, admin dashboard, parent mode, red-flag detection, and counselor handoff summaries.
